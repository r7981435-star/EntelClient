# Entel Client

**Minecraft Fabric 1.21.11 | Java 21 | Early development**

A custom client-side utility and cheat mod with configurable modules and an in-game GUI.

## Current features

- ClickGUI (Right Shift by default)
- GUI key selection: Right Shift, Right Control or Insert
- AutoSprint and AutoRespawn
- BaseFinder: scans the current chunk for chests, barrels, crafting tables, furnaces, glass and ender chests, reporting coordinates in chat
- Persistent module settings

## Download and install

1. Visit [GitHub Actions](https://github.com/r7981435-star/EntelClient/actions).
2. Select a successful build and download the EntelClient artifact.
3. Extract the ZIP and place the regular mod JAR in your Minecraft mods folder alongside Fabric API for 1.21.11.
4. Launch Minecraft with Fabric and press Right Shift.

## Build from source

Requires Java 21 and Gradle. Run `gradle build`. Output is in `build/libs/`.
